## 팀플 상품관리 프로그램 만들기
1. Git 설치
2. Github 회원가입
3. Github 레포지토리(저장소) 생성
    - 팀 대표 1명이 생성
4. Github 팀원 초대
5. 레포지토리 복제 - Git Clone
    1. ctrl + shift + P ([보기] > [명령 팔레트])
    2. Git Clone
    3. Github 레포지토리
        1) Code 초록색 버튼
        2) URL 복사
    4. URL 입력 (~~~~~.git)
    5. 작업 폴더 선택 
6. 시작 프로젝트 생성 후 업로드
    - 팀 대표 1명이 진행
    - Java Project 생성
    - Git Push (업로드)
7. 팀원들이 최초 프로젝트 복제 - Git Clone
8. 기능 역할 분담하기
    - 기능별
        * DDL작성/콘솔화면/Product(상품객체)/상품 목록/조회/등록/수정/삭제    
    - 로직별
        * DDL작성&DTO/콘솔화면/Service/DAO
9. 개별 작업 Branch 만들기
    * 일반적으로는 기능별로 브랜치를 생성한다.
    - 팀원별로 만들어봐도 좋을 것같습니다.
    ex) 팀원 닉네임별로 브랜치 만들어보기
    - hanna
    - jaeah
    - hyojeong
    - yeeun
    - main
10. 역할 분담 기능 개발 시작!
11. 내가 완성한 코드 업로드 - git push 
    1) 변경 사항 스테이징
    2) 커밋
    3) 푸시
12. main 브랜치에 병합 - git merge
    1) Github
    2) Pull Request
    3) New Pull Request
    4) Create Pull Request > Merge Pull Request > Confirm Merge
13. 다른 팀원이 작성한 코드 이어받기 - git pull & git merge
    1) 내 변경 사항 커밋
    2) main 브랜치로 전환
    3) 풀
    4) 내 브랜치로 전환
    5) 분기 > 병합 > main

14. 이어서 작업
15. 최종 완성을 main 브랜치에 병합
